## 🚀 How to View the Landing Page

### Option 1: Direct File Open
Simply double-click [`index.html`](index.html) or right-click and choose **"Open with Google Chrome"** (or any browser).

### Option 2: Run a Local Server
Run this command in terminal inside this folder:
```bash
python3 -m http.server 8080
```
Then visit: **`http://localhost:8080`**

## 🌐 How to Deploy Live for Free in 2 Minutes

1. **Vercel / Netlify**: Drag-and-drop this entire folder onto [Vercel](https://vercel.com) or [Netlify](https://netlify.com) to get a free live URL (e.g., `https://rsa-pro-fitness.vercel.app`).
2. **GitHub Pages**: Push this repo to GitHub, go to `Settings > Pages`, and select `main` branch to host it at `yourusername.github.io/rsa-gym`.
3. **Custom Domain**: Connect your domain (like `rsaprofitness.com` or `rsagym.in`) with 1-click in Vercel/Netlify DNS settings.
